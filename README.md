☁️ **AWS Cloud Practitioner – Guía Interactiva de Estudio (CLF-C02)**

Plataforma web interactiva desarrollada con **HTML5, CSS3 y JavaScript**, diseñada para facilitar el aprendizaje y la preparación para la certificación AWS Certified Cloud Practitioner (CLF-C02).

El sistema incluye una guía de servicios AWS organizada por categorías, un simulador de examen con preguntas de opción múltiple, estadísticas de rendimiento, sistema de favoritos y una interfaz moderna, responsive y adaptable a modo claro y oscuro.

**🚀 Características principales**
- 📚 Guía de servicios y conceptos de AWS.
- 🧠 Simulador de examen con 10, 20, 30 o 50 preguntas.
- 📊 Dashboard de estadísticas y resultados.
- ✅ Retroalimentación y revisión de respuestas.
- ⭐ Sistema de favoritos.
- 🔍 Buscador dinámico de servicios.
- 🌙 Modo claro y oscuro.
- 📱 Diseño responsive.
- 💾 Almacenamiento local mediante localStorage.

**🛠️ Tecnologías:** HTML5, CSS3, JavaScript Vanilla y Web Storage API.

Proyecto educativo independiente, sin necesidad de frameworks, servidores backend ni bases de datos.
